# كناش التقدية (Taqdiya Ledger) 🛒🇲🇦

**كناش التقدية** هو تطبيق أندرويد محلي 100% (يعمل بدون إنترنت تماماً) صُمم خصيصاً لتنظيم التقدية المغربية اليومية والأسبوعية، وتتبع ميزانية الجيب («شحال فالجيب»)، وحساب المشتريات عند كل بائع (مول الخضرة، العطار/مول الحانوت، الكزار، مول الدجاج، مول الحوت، مول البيض...) بالدرهم والريال المغربي مع ذاكرة ذكية للأثمنة.

---

## ✨ المميزات الرئيسية

### 1. شاشة «التحضير» في البيت (بلا كيبورد وبلمسة إبهام واحدة)
- **لوحة الإضافة السريعة باللمس (+)**: شبكة أزرار لمسية كبيرة مقسمة حسب البائع، تتيح إضافة النواقص أو إزالتها بلمسة واحدة دون الحاجة للكتابة.
- **قاموس السلع الذكي**: يتعلم تلقائياً أي غرض جديد تكتبه ويربطه بالبائع المخصص له ليظهر كزر جاهز في المرات القادمة.
- **إدارة البائعين والقاموس**: إمكانية إضافة بائعين جدد، تعديل أسمائهم وأيقوناتهم، أو نقل السلع بين البائعين بسهولة.
- **مشاركة القائمة عبر واتساب**: إرسال قائمة النواقص مرتبة ومفصلة حسب كل بائع بضغطة زر.

### 2. شاشة «عند البائع» في السوق (حاسبة الميزان الفورية)
- **تبديل سريع بين بائعي الجولة**: يعرض فقط البائعين الذين لديك أغراض عندهم اليوم مع عداد واضح (`تم شراء X من Y`).
- **حاسبة الميزان المغربية بـ 3 طرق**:
  1. **بالوزن (الكيلو)**: أزرار سريعة (كيلو، نص كيلو، رابعة، نص رابعة، 3 رابعات، 2 كيلو) أو إدخال وزن حر، مع إمكانية إضافة ثمن التنقية/الريش.
  2. **مبلغ مقطوع (شحال ما عطى الله)**: للشراء بمبلغ محدد مباشرة (مثلاً: ربيع بـ 3 دراهم، نعناع بـ 2 دراهم).
  3. **بالعدد / البيض / الباكيه**: حساب فوري بالوحدة أو الحبة.
- **مؤشر وكناش الأثمنة الذكي**: يقارن ثمن اليوم بمتوسط أثمنتك السابقة لنفس السلعة وينبهك فوراً إذا كان الثمن منخفضاً (فرصة) أو مرتفعاً عن المعتاد.
- **المسامحة فالصرف والصرف العالق**:
  - عند الدفع للبائع، يمكنك تسجيل المبلغ المدفوع فعلياً ليحسب التطبيق توفير «المسامحة فالصرف» تلقائياً.
  - تتبع الصرف العالق مع كل بائع (`بقا ليا عندو` أو `بقا ليه عندي`) وتذكيرك به في الجولة القادمة حتى تتم تصفيته.
- **إبقاء الشاشة مضاءة في السوق**: زر سريع لمنع انطفاء شاشة الهاتف أثناء الوقوف أمام الميزان.

### 3. شاشة «جرد الجيب» والأرشيف
- **كشف جرد الجيب المفصل**: يعرض بوضوح المبلغ الذي خرجت به من البيت، مجموع ما صرفته فعلياً عند البائعين وفي المصاريف العابرة (خبز، طاكسي، أكياس...)، والباقي المفترض في جيبك الآن.
- **أرشيف الجولات السابقة**: حفظ سجل كامل لكل جولة تقدية مع إمكانية ترحيل النواقص المتبقية تلقائياً إلى الجولة الجديدة.

### 4. الخصوصية، الأمان، وتخصيص المظهر
- **عين الخصوصية في السوق (`***`)**: إخفاء المبالغ بضغطة واحدة عن أعين المتطفلين، مع خيار تخصيص النطاق في الإعدادات:
  - **إخفاء المبالغ كلها** (رصيد الجيب وأثمنة السلع).
  - **إخفاء المبلغ في الجيب فقط** (مع بقاء أثمنة السلع وحساب البائع ظاهرة أمامك).
- **قفل التطبيق برمز سري (PIN)**: حماية كناش التقدية برمز سري من 4 أرقام.
- **العملة المزدوجة (الدرهم والريال المغربي)**: إظهار أو إخفاء المعادل بالريال المغربي (`1 درهم = 20 ريال`) في أي وقت.
- **الوضع الليلي المريح للعين وتكبير الخط**: دعم كامل للوضع الليلي الدافئ بدون أي وميض أبيض عند الفتح، مع 3 أحجام للخط والبطاقات (`عادي`، `كبير`، `ضخم`) متوافقة مع جميع شاشات الهواتف.
- **النسخ الاحتياطي والاسترجاع (JSON)** + **ودجت الشاشة الرئيسية (Home Screen Widget)**.

## 🛠️ البنية التقنية
- **اللغة وإطار العمل**: Kotlin + Jetpack Compose (Material Design 3) بواجهة عربية كاملة من اليمين إلى اليسار (`RTL`).
- **قاعدة البيانات المحلية**: Room SQLite Database (تخزين محلي دائم 100% بدون إنترنت مع دعم الترحيل الآمن للبيانات `Migrations`).
- **المعمارية**: MVVM (`HomePrepViewModel` + `TaqdiyaRepository` + `StateFlow`).
