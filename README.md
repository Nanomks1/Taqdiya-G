# التقدية - كناش التقدية (Taqdiya Ledger) 🛒🇲🇦

**التقدية (كناش التقدية)** هو تطبيق أندرويد محلي 100% (يعمل بدون إنترنت تماماً) صُمم خصيصاً لتنظيم التقدية المغربية اليومية والأسبوعية، وتتبع ميزانية الجيب («شحال فالجيب»)، وحساب المشتريات عند كل بائع (مول الخضرة، العطار/مول الحانوت، الكزار، مول الدجاج، مول الحوت، مول الفواكه...) بالدرهم والريال المغربي مع ذاكرة ذكية للأثمنة وسرعة إدخال فائقة تناسب السوق.

---

## ✨ المميزات الرئيسية

### 1. شاشة «التحضير» في البيت (بلا كيبورد وبلمسة إبهام واحدة)
- **لوحة الإضافة السريعة باللمس (+)**: شبكة أزرار لمسية كبيرة مقسمة حسب البائع، تتيح إضافة النواقص أو إزالتها بلمسة واحدة دون الحاجة للكتابة.
- **إزالة نظيفة للنواقص المضافة بالخطأ**: إلغاء تحديد أي سلعة غير مشتراة يزيلها فوراً من قائمة اليوم دون تلويث سلة المحذوفات، مع إمكانية التراجع الفوري (`تراجع الآن`).
- **قاموس السلع الذكي**: يتعلم تلقائياً أي غرض جديد تكتبه ويربطه بالبائع المخصص له ليظهر كزر جاهز في المرات القادمة.
- **إدارة البائعين والقاموس**: إمكانية إضافة بائعين جدد، تعديل أسمائهم وأيقوناتهم، أو نقل السلع بين البائعين بسهولة.
- **مشاركة القائمة عبر واتساب**: إرسال قائمة النواقص مرتبة ومفصلة حسب كل بائع بضغطة زر.

### 2. شاشة «عند البائع» في السوق (حاسبة الميزان الفورية)
- **تبديل سريع بين بائعي الجولة**: يعرض فقط البائعين الذين لديك أغراض عندهم اليوم مع عداد واضح (`X من Y`).
- **بطاقات سلع واضحة ومريحة للعين**: تجمع اسم السلعة ومقدارها وسعرها المعتاد في كتلة بصرية متناسقة لقراءة سريعة بدون تشتت.
- **حاسبة الميزان المغربية بـ 3 طرق**:
  1. **بالوزن (الكيلو)**: أزرار سريعة (كيلو، نص كيلو، رابعة، نص رابعة، 3 رابعات، 2 كيلو) أو إدخال وزن حر، مع إظهار ذكي لخيار **ثمن التنقية** فقط عند شراء السمك/الحوت أو الدجاج/الدواجن.
  2. **مبلغ مقطوع**: للشراء بمبلغ محدد مباشرة (مثلاً: ربيع بـ 3 دراهم، نعناع بـ 2 دراهم).
  3. **بالعدد / البيض / الباكيه**: حساب فوري بالوحدة أو الحبة أو البلاطو.
- **مؤشر وكناش الأثمنة الذكي**: يقارن ثمن اليوم بمتوسط أثمنتك السابقة لنفس السلعة وينبهك فوراً إذا كان الثمن منخفضاً أو مرتفعاً عن المعتاد.
- **المسامحة فالصرف والصرف العالق**:
  - عند الدفع للبائع، يمكنك تسجيل المبلغ المدفوع فعلياً ليحسب التطبيق توفير «المسامحة فالصرف» تلقائياً.
  - تتبع الصرف العالق مع كل بائع (`بقا ليا عندو` أو `بقا ليه عندي`) وتذكيرك به في الجولة القادمة حتى تتم تصفيته.
- **إبقاء الشاشة مضاءة في السوق**: زر سريع لمنع انطفاء شاشة الهاتف أثناء الوقوف أمام الميزان.

### 3. شاشة «جرد الجيب» والأرشيف
- **كشف جرد الجيب المفصل**: يعرض بوضوح المبلغ الذي خرجت به من البيت، مجموع ما صرفته فعلياً عند البائعين وفي المصاريف العابرة (خبز، طاكسي، أكياس...)، والباقي المفترض في جيبك الآن.
- **أرشيف الجولات السابقة**: حفظ سجل كامل لكل جولة تقدية مع إمكانية ترحيل النواقص المتبقية تلقائياً إلى الجولة الجديدة.

### 4. الخصوصية، الأمان، وتخصيص المظهر والخطوط
- **4 أنساق ألوان متكاملة (تعمل في الوضعين النهاري والليلي)**:
  1. **الطين الأصيل (Terracotta)** — دافئ ومتوازن.
  2. **أخضر هادئ (Calm Sage)** — مريح وهادئ للعين.
  3. **أزرق بارز (Vibrant Cobalt)** — تباين عالٍ جداً تحت أشعة الشمس.
  4. **عنابي وزمرد (Royal Plum)** — مستوحى من ألوان الزليج المغربي.
- **نظام الخطوط المتقدم واستيراد الخطوط يدوياً (`.ttf` / `.otf`)**:
  - اختيار بين الخطوط المدمجة (**خط القاهرة Cairo**، **خط تجوّل Tajawal**، **خط النظام**) أو **رفع خط يدوي مخصص** من ذاكرة الهاتف بتحديد ملفات الأوزان الثلاثة (**Regular** و **Medium** و **Bold**) مع معاينة حية فورية.
- **التحكم في المؤثرات الحركية (Animations)**: الاختيار بين **حركات خفيفة وسريعة**، **حركات كاملة**، أو **إطفاء الحركات تماماً** لأقصى سرعة استجابة.
- **عين الخصوصية في السوق (`***`)**: إخفاء المبالغ بضغطة واحدة مع خيار تخصيص النطاق (**إخفاء المبالغ كلها** أو **إخفاء المبلغ في الجيب فقط**).
- **قفل التطبيق برمز سري (PIN)**: حماية كناش التقدية برمز سري من 4 أرقام.
- **النسخ الاحتياطي والاسترجاع (JSON)** + **ودجت الشاشة الرئيسية (Home Screen Widget)**.

## 🛠️ البنية التقنية
- **اللغة وإطار العمل**: Kotlin + Jetpack Compose (Material Design 3) بواجهة عربية كاملة من اليمين إلى اليسار (`RTL`).
- **معرّف الحزمة (Package Name / Application ID)**: `az.pdr.taqdiya2`.
- **قاعدة البيانات المحلية**: Room SQLite Database (تخزين محلي دائم 100% بدون إنترنت مع دعم الترحيل الآمن للبيانات `Migrations` حتى الإصدار `v8`).
- **المعمارية**: MVVM (`HomePrepViewModel` + `TaqdiyaRepository` + `StateFlow`).
